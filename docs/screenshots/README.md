# Screenshot PennyPilot

Letakkan screenshot aplikasi di folder ini, lalu aktifkan komentar gambar pada `README.md` utama.

Nama file yang direkomendasikan:

- `dashboard.png` — dashboard bulanan dengan KPI, grafik, dan pengeluaran tidak biasa.
- `import.png` — wizard impor CSV dengan pratinjau dan ringkasan validasi.
- `budgets.png` — anggaran, aktual, proyeksi, dan saran.
- `rules.png` — editor aturan kategori.

Jangan menyertakan data keuangan pribadi pada screenshot. Gunakan dataset demo sintetis.
